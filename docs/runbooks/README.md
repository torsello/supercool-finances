# Runbooks

For operators: what to do when something goes wrong, or before a routine operation. Every runbook has the same sections: symptoms and alerts, impact, diagnosis (the queries, commands and metrics to run), mitigation step by step, verification, and follow-up. The signals they start from are described in [observability.md](../observability.md): the CloudWatch [alarms](../observability.md#alarms) of the AWS deployment, and the [alerts without an alarm](../observability.md#alerts-without-an-alarm), which name a signal and a condition but are not deployed. The AWS deployment is in [aws.md](../deployment/aws.md).
