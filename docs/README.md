# Documentation

A map of the documentation: what each document covers and who it is for. Start with the [README](../README.md), which explains what the service does, how it works and how to run it, with the diagrams the documents below link to.

| Reader      | Start with                                                                                                                                     |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Reviewer    | The [README's reviewer's guide](../README.md#reviewers-guide), then [architecture.md](architecture.md) and [traceability.md](traceability.md). |
| API client  | [api/README.md](api/README.md), then [api/openapi.yaml](api/openapi.yaml) or Swagger UI at `/docs`.                                            |
| Operator    | [observability.md](observability.md), [runbooks/](runbooks/README.md) and [deployment/aws.md](deployment/aws.md).                              |
| Contributor | [development.md](development.md), [AGENTS.md](../AGENTS.md) and the [specs](../specs/README.md).                                               |
